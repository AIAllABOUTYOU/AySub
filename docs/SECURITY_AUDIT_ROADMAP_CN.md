# AySub 安全审计与风控路线

本文档记录 AySub 当前安全审计、风控和内容审核相关能力的实现边界。它是 README 中“安全与风控”声明的验收口径，不替代部署安全基线、反代配置或生产运维制度。

## 当前结论

当前代码库已实现 NewAPI 风格的安全审计与风控中心：

- 安全审计日志、事件、策略、封控对象和审计导出。
- 审计哈希链完整性校验。
- 内容审核配置、状态、日志、用户解封和 flagged hash 清理。
- 用户安全中心、TOTP、恢复码、敏感操作二次验证和会话撤销。

README 不把以下内容写成已完成：

- Passkey/WebAuthn 登录。
- 企业级 SIEM/SOC 对接。
- 跨实例审计链共识或外部不可篡改存证。
- 完整的自动化安全运营规则引擎。

## 已实现能力

### 安全审计

已实现能力：

- 记录安全相关操作和事件。
- 支持审计日志查询、筛选和导出。
- 支持事件视图和策略视图。
- 支持封控对象管理。
- 支持哈希链完整性校验，用于发现审计日志链路被破坏的情况。

主要入口：

- 管理侧：`/admin/security`
- 管理 API：`/api/v1/admin/security/*`

### 风控中心

已实现能力：

- 风控对象管理。
- 风控策略配置。
- 用户解封流程。
- 与安全审计、内容审核和请求日志形成运营闭环。

主要入口：

- 管理侧：`/admin/risk-control`
- 管理 API：`/api/v1/admin/risk-control/*`

### 内容审核

已实现能力：

- 内容审核配置。
- 审核状态查看。
- 审核日志查询。
- flagged hash 清理。
- 用户解封。

主要入口：

- 管理侧：安全审计/风控相关页面
- 管理 API：`/api/v1/admin/risk-control/*`

### 用户侧安全能力

已实现能力：

- 用户安全事件查看。
- TOTP 开启、验证和关闭。
- 恢复码。
- 敏感操作二次验证。
- 通知邮箱。
- 第三方账号绑定。
- 会话撤销。

主要入口：

- 用户侧：`/security`
- 用户 API：`/api/v1/user/security/events`、`/api/v1/user/totp/*`、`/api/v1/user/notify-email/*`

## 实现边界

- 审计能力以应用内事件和数据库记录为准，不等同于外部不可篡改日志系统。
- 哈希链用于完整性检查，不替代备份、权限隔离和数据库审计。
- 内容审核依赖当前配置的审核策略和上游能力，不能承诺覆盖所有违规内容。
- 风控策略应和请求日志、账号错误、用户行为一起分析，不能单独作为处罚依据。
- 生产环境仍需要正确配置 JWT、TOTP 加密密钥、反代可信代理、HTTPS、数据库权限和备份。

## 验收标准

- 安全事件、策略和封控对象可以在管理后台查询和操作。
- 用户侧安全中心可以完成 TOTP、恢复码、通知邮箱和会话撤销流程。
- 审计导出不泄露密钥、Cookie、完整敏感请求体或内部错误栈。
- 哈希链校验能报告链路异常。
- 风控/内容审核相关操作进入审计日志或可追踪运营记录。
